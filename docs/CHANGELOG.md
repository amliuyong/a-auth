# Changelog

All notable user-facing changes to Agent Auth will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/) after the first
stable release. Until then, minor releases may include breaking changes to
configuration, APIs, deployment resources, or SDKs.

## [Unreleased]

This repository starts with a clean public history. Changes made after the
initial open-source release will be recorded here.

## [0.1.0] - 2026-08-26

### Added

- Initial open-source release of the Rust authorization server and AWS CDK
  deployment.
- React administration and user interface.
- TypeScript and Python resource-server SDKs.
- Capability specifications, conformance inventory, deployment runbooks, and
  automated tests.
